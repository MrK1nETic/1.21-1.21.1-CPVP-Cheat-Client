# Langr Client (Potato)

A comprehensive Fabric-based utility mod and PvP client designed for Minecraft 1.21 and 1.21.1.[cite: 1] Built with a highly customizable ClickGUI and an advanced event-driven architecture, this mod features specialized modules for Crystal PvP (CPvP), movement optimization, and combat assistance.[cite: 1]

## ✨ Key Features

* **Advanced Combat & CPvP Modules:** Includes automated systems like `CrystalMod`, `AnchorItem`, and `TotemInventory` management for high-tier PvP combat.[cite: 1]
* **Customizable ClickGUI & HUD Editor:** A fully interactive graphical interface featuring a ClickGUI, setting sliders, color boxes, and a dedicated interactive HUD editor (`HudEditorGui`).[cite: 1]
* **Custom Font Engine:** Smooth, anti-aliased text rendering using custom `.ttf` fonts via a custom Glyph font renderer.[cite: 1]
* **Friend Manager:** Built-in system (`FriendsWindow`) to manage allies, track targets, and prevent friendly fire.[cite: 1]
* **Discord Webhook Integration:** Automated Discord logging, embeds, and status updates directly from the client.[cite: 1]
* **Event-Driven Architecture:** Highly optimized event system handling 3D rendering, network packets, entity spawning, block breaking, and peripheral inputs.[cite: 1]
* **Custom Shaders:** Includes specialized fragment and vertex shaders for custom rendering, outlines, and ESPs.[cite: 1]

## 🚀 Installation & Usage

1. Download and install the [Fabric Loader](https://fabricmc.net/) for Minecraft 1.21 or 1.21.1.
2. Download the latest mod `.jar` file (e.g., `language-reload-1.7.6+1.21.1.jar`) from the Releases tab.[cite: 1]
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch the game and load into a world or server.
5. **Press `Right Alt`** to open the ClickGUI and access all mod features and settings.

## 🛠️ Module Categories

* **CPvP:** AutoCrystal, AnchorAssist, AutoTotem inventory management.[cite: 1]
* **Movement:** Player mobility, traversal utilities, and packet handling.[cite: 1]
* **Sword/Combat:** Block defense, attack listeners, and target margin adjustments.[cite: 1]
* **Render:** Visual enhancements, custom outlines, array lists, and 3D event rendering.[cite: 1]
* **Misc/Client:** Core client settings, profiles, and Discord webhook configurations.[cite: 1]
